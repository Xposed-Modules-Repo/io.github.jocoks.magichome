# MagicHome

让荣耀的上滑回桌面、最近任务退出、按返回退出，都落到**你指定的第三方桌面**。

荣耀 MagicOS 不允许把第三方桌面设为默认桌面，「上滑回桌面」在系统内部是**把荣耀桌面任务置前**，
不是发 HOME intent，所以改默认桌面、改 intent 都没用。本模块在荣耀桌面（Quickstep）进程里做重定向，
只在你真的要回桌面时才跳转；进最近任务、快速切应用都不受影响。

已在荣耀 MagicOS 11 / Android 17 实机测试。

## 功能

- **上滑就进你的桌面**：在 App 里上滑回桌面、或在荣耀桌面底部边缘快速上滑，都落到你指定的桌面；上滑停顿进最近任务、快速切应用不会误跳。
- **离开应用/最近任务也进你的桌面**：最近任务里点空白、再上滑一次，或从 App 按返回键退出，都进你的桌面（设置页可关）。
- **最近任务里更好用**：底部显示运存占用（总量 / 空闲 / 已用百分比，每秒刷新）；长按卡片约 0.5 秒打开该应用的「应用信息」页。
- **目标桌面随便换**：设置页列出已安装的桌面，点一下或输入包名，几秒生效。
- **冷启动预热**：回桌面前静默拉起目标桌面进程，减少首屏等待。

## 支持环境

| 项目 | 要求 |
|---|---|
| 系统 | 荣耀 MagicOS（Android 17 实测） |
| 框架 | LSPosed，libxposed API 102+ |
| 作用域 | `com.hihonor.android.launcher`（必选），`com.hihonor.hnofficelauncher`（可选） |
| 桌面 | 任意第三方桌面；Nova 有完整预热支持 |

## 安装

1. 安装 APK。
2. LSPosed 管理器 → 模块 → 启用 MagicHome，作用域勾选 `com.hihonor.android.launcher`。
3. `am force-stop com.hihonor.android.launcher`（或重启手机）让模块生效。
4. 打开设置页，选择或输入目标桌面包名并保存。

> 包名 `io.github.jocoks.magichome`。从更早版本升级需先卸载旧版。

## 使用效果

| 你的操作 | 预期结果 |
|---|---|
| 任意 App 上滑 / 桌面底部边缘上滑 | 约 0.25s 进入你指定的桌面 |
| 上滑并停顿、或上滑偏高 | 正常停在最近任务，不会被弹走 |
| 最近任务里点卡片 | 正常进入该 App |
| 最近任务里点空白 / 再上滑、或从 App 按返回 | 约 0.1s 进入你指定的桌面 |
| 进最近任务 | 底部显示运存占用；长按卡片可开应用信息 |

## 已知限制

- 跳转发生在荣耀桌面已显示之后，个别机型可能瞥见一瞬间的荣耀桌面。
- 响应速度受荣耀转场动画影响：**设置 → 无障碍 → 关闭动画**会更快。
- 只作用于荣耀桌面进程，不改系统文件、不改默认桌面，卸载即恢复。
