# MagicHome · 让荣耀的上滑回桌面进入你指定的第三方桌面

荣耀 MagicOS 不允许把第三方桌面设为系统默认桌面，而「上滑回桌面」这个手势在系统内部
并不是发送 HOME intent，而是**把荣耀桌面任务置前**。所以无论怎么改默认桌面、怎么改
HOME intent，最终看到的永远是荣耀桌面。

**MagicHome** 在荣耀桌面（Quickstep）进程里做重定向：当手势终点确实是「回桌面」时，
把你带到你自己指定的第三方桌面；上滑停顿进最近任务、快速切换应用都不受影响。

已在荣耀 MagicOS 11 / Android 17 实机测试，支持任意第三方桌面（默认 Nova Launcher）。

---

## 功能

- **上滑回桌面 → 你的桌面**：任意 App 里上滑，落到指定桌面（默认 `com.teslacoilsw.launcher`）。
- **不误触发**：钩住荣耀自研 Quickstep 的手势终点 `GestureState#setEndTarget`，只有终点是
  `HOME` 才放行；进最近任务（`RECENTS`）、快速切应用、从桌面点开 App 都不会误跳。
- **停在荣耀桌面时快速上滑**：从屏幕最底部边缘快速上滑，直接进入指定桌面。
- **最近任务长按卡片**：按住卡片约 0.5 秒，打开该应用的系统「应用信息」页（卸载、强行停止、权限、存储）。
- **最近任务退出 / 按返回键都进你的桌面**：在最近任务里不点卡片、而是点空白处或再上滑一次，
  或者从任意 App 按返回键退出，都会进入你指定的桌面（而不是停到荣耀桌面）；刚按过卡片 400ms 内不接管，
  设置页可单独关闭这个行为。
- **目标桌面可换**：内置设置页，点选或直接输入桌面包名即可，保存后几秒内生效，无需重启。
- **冷启动预热**：开机首次回桌面、以及每次上滑起手时静默拉起目标桌面进程，减少首屏等待。

## 支持环境

| 项目 | 要求 |
|---|---|
| 系统 | 荣耀 MagicOS（Android 17 实测通过） |
| 框架 | LSPosed，libxposed API 102 及以上 |
| 作用域 | `com.hihonor.android.launcher`（必选）；`com.hihonor.hnofficelauncher`（可选） |
| 桌面 | 任意第三方桌面；Nova Launcher 有完整预热支持（依赖其导出的 ContentProvider） |

## 安装

1. 安装 `MagicHome-x.y.z.apk`。
   > 2.7.1 起包名为 `io.github.jocoks.magichome`（为进入 LSPosed 官方仓库而改名）。
   > **从 2.7.0 及更早版本升级必须先卸载旧版**，包名不同，配置不会迁移。
2. 打开 LSPosed 管理器 → 模块 → 启用 **MagicHome**，作用域至少勾选 `com.hihonor.android.launcher`。
3. 让模块对新进程生效：在终端执行 `am force-stop com.hihonor.android.launcher`（系统会立刻重新拉起桌面），或直接重启手机。
4. 打开 MagicHome 的设置页，选择或输入你的目标桌面包名并保存。

## 使用效果

| 你的操作 | 预期结果 |
|---|---|
| 任意 App 里快速上滑 | 约 0.25s 后进入你指定的桌面 |
| 上滑并停顿 | 正常停在最近任务，卡片可滑动 |
| 最近任务里点一个 App | 正常进入该 App，不会被桌面顶掉 |
| 最近任务里点空白处 / 再上滑一次 | 约 0.1s 后进入你指定的桌面（2.7.2 起，设置页可关） |
| 从任意 App 按返回键退出 | 约 0.1s 后进入你指定的桌面（2.7.5 起，与上面同一个开关） |
| 停在荣耀桌面时从底部边缘快速上滑 | 直接进入你指定的桌面 |
| 最近任务里长按卡片约 0.5s | 打开该应用的「应用信息」页 |

## 已知限制

- 跳转发生在荣耀桌面已经显示之后，个别机型上可能瞥见一瞬间的荣耀桌面。
- 响应速度受荣耀桌面自身的转场动画影响：**打开「设置 → 无障碍 → 关闭动画」会更快**。
- 荣耀桌面大版本更新后，内部状态类名可能变化，需要适配（日志里的 `state -> xxx` 可直接用于定位）。
- 模块只作用于荣耀桌面进程，不修改系统文件、不改系统默认桌面配置，卸载即完全恢复。
- 某些第三方桌面不导出 ContentProvider，此时只缺少「预热」，功能不受影响。

## 卸载

在 LSPosed 管理器里停用/卸载本模块，卸载应用即可恢复原状；如桌面行为没有立刻恢复，
执行一次 `am force-stop com.hihonor.android.launcher` 或重启手机。
